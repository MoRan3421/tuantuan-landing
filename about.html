✨ About 团团 · 关于团团

Honest version status, tech stack, commercial roadmap · 真实版本状态、技术栈与商业路线图

EN — 团团 is a pre-alpha Discord community bot built with a commercial-grade architecture from day one. The goal is simple: become the best, most feature-rich bot for multilingual communities in Southeast Asia and beyond — with proper monetization, a web dashboard, and a self-sustaining ecosystem.

中 — 团团 是一款预发布版 Discord 社区机器人，从第一天起就以商业级架构设计。目标很简单：成为东南亚及全球多语言社区中功能最强、最完善的机器人——配备完整的变现系统、网页控制台，以及自我持续发展的生态体系。
TypeScript strict
Discord.js v14
PostgreSQL 16
Redis 7 + BullMQ
Prisma ORM
40+ DB models
Node.js 20 LTS
Fly.io hosting

💼 Commercialization Plan · 商业化计划

💳

Server Subscriptions

Monthly premium plans per server. Stripe integration for USD / crypto payments.
按服务器收月费，Stripe 集成。

🌟

Cosmetic Shop

Role badges, profile frames, custom title cards sold with in-bot currency or real money.

Server Marketplace
